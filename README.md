# Genki Wave helper

Signed and notarized builds of `wave-helper`, the background program the
[Genki Wave Raycast extension](https://www.raycast.com/) uses to talk to the
Genki Wave ring over Bluetooth. The extension downloads the release it was
built for and checks its SHA-256 before running it.

There's no need to download anything here yourself: install the extension in
Raycast and it takes care of the helper.
